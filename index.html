NeoUtlのお部屋

NeoUtlとは…

AviUtl 1.10 & ExEdit 0.92の操作感を踏襲しつつ、AviUtlを超える性能を持つ動画編集ソフトを目標とするプロジェクトです。
目標達成の為に、「LinuxやmacOSでも動く、より速い、より安全、より拡張性が高い、AviUtlライクな自由ソフトウェア」を開発しています。

★ インフォメーション ★

コミュニティを開設しました

NeoUtlについて気軽に話せるコミュニティです。
開発状況の確認、質問、バグ報告、機能への提案などを、 NeoUtlの開発者やユーザーと交流しながら行えます。 こちらから参加することができます。
デスクトップやモバイルでは Zulipアプリも利用できます。

NeoUtl 0.7を公開しました

多言語化対応（エフェクトメタデータ含む）、アップデート通知機能、複数プロジェクトを同時に開く機能、クラッシュレポート送信機構、テーマ機構、アクセシビリティ対応、グループ制御オブジェクト（フレームバッファオブジェクト、カメラ制御オブジェクトの機能を含む）、ディスプレイスメントマップエフェクト、クリッピング機能、prostによる高速IO、デコーダーの仮開通等、様々な機能が実装されました。
現在、0.8に向け、デコーダー・エンコーダーの安定化、音声プラグインの安定化、APIの整理等に取り組んでおります。
今後共、NeoUtlにご期待下さい。

ビルド手順
最新のNeoUtl（mainブランチ）はRustで実装されています。ビルドを行うには、予め Rust、Clang、Mold、FFmpeg をシステムにインストールしてください。
ソースコードの取得とビルド
git clone "https://codeberg.org/taisho-guy/NeoUtl.git"
cd NeoUtl
git switch main
cargo xtask build --release
実行可能ファイルは target/release 以下に生成されます。
AviQtlをビルドする場合

Python3およびPySide6環境が必要です。

git switch aviqtl
python3 BUILD.py
実行可能ファイルは build 以下に生成されます。

★ 採用技術 ★

NeoUtlは、以下の素晴らしいオープンソースプロジェクトと言語の上に成り立っています。

言語・フレームワーク
Rust 安全性と高パフォーマンスを両立した、現行プロジェクトのメイン実装言語です。
Language
egui UI/UXの構築に採用されている、ネイティブかつ軽量なGUIツールキットです。
GPLv3 / Commercial
wgpu GPUを最大限に引き出し、クロスプラットフォームで高速なプレビューを支えるグラフィックスAPIです。
MIT / Apache-2.0
Slang エフェクト等のシェーダ記述に採用されている、Khronosが管理するシェーディング言語・コンパイラです。
MIT
Shipyard データの効率的な管理と高速な処理を支える、Entity Component System (ECS) クレートです。
MIT / Apache-2.0
Tokio マルチスレッド環境での非同期処理やイベント駆動制御を司る基盤です。
MIT
symphonia 純Rust実装の音声デコードを担い、gpu-videoを補完します。
MPL-2.0
